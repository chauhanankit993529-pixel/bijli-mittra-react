# Bijli Mittra - VS Code Project

Technology:
- HTML
- CSS
- JavaScript
- Browser localStorage
- Browser Geolocation API

How to run:
1. Open this folder in VS Code.
2. Open index.html.
3. Run it in a browser (or use Live Server if installed).

Teacher explanation:
"Bijli Mittra ek electrician-finding web application hai. Isme customer electrician ko search, rating, call aur book kar sakta hai. Demo bookings browser localStorage me save hoti hain."
